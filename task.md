
# Task

Replace current perly.y parser with GLR parser.

# Requirements

- parser is fully generated by bison
- parser should support multiple instances

# Code layout

Current parser uses modified files implementing LALR parser generated by older version of bison
- perly.y - grammar definition
- toke.c - lexer

GLR parser will use toke.c but its sources (and generated files) will be:
- located in directory `perly-glr`
- grammar file will be named `perly-glr.y`

I want to grammar files as clean as possible so there will be files:
 - `perly-glr.requires.h`  - for `%code requires{}`
 - `perly-glr.provides.h`  - for `%code provides{}`
 - `perly-glr.actions.inc` - for `%{}`
 - `perly-glr.code.inc`    - included after grammar

These will be included with path relative to project root.
